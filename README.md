# Gun Arena

Браузерный сетевой шутер от первого лица в духе Pixel Gun, но без пиксельной графики: процедурные PBR-текстуры, детализированное оружие, освещение с тенями и комнаты для игры с друзьями по коду.

Работает как статический сайт (GitHub Pages и любой другой хостинг), серверная часть не нужна.

## Что внутри

- **Графика:** Three.js, небо с физическим рассеянием, солнечные тени, отражения окружения, туман, ACES tone mapping. Текстуры бетона, кирпича, контейнеров, ящиков, рифлёного металла и дерева генерируются в браузере вместе с картами нормалей и шероховатости.
- **Оружие:** «Кобра» (пистолет), «Вихрь» (штурмовая винтовка с коллиматором), «Гром» (помповый дробовик), «Сокол» (снайперская винтовка с оптикой). Модели из десятков деталей, руки в перчатках, анимации отдачи, перезарядки, помпы, покачивания, прицеливание через прицел, вспышки, трассеры, гильзы, следы от пуль.
- **Карты:** «Порт» (контейнерный терминал со складом и мостками) и «Руины» (разрушенный квартал на закате).
- **Режимы:** все против всех и команда на команду; лимит убийств и времени, боты трёх уровней сложности, аптечки.
- **Комнаты:** создание комнаты с выбором карты и правил, код из 5 символов и ссылка-приглашение, лобби со списком игроков, готовностью, командами, чатом и исключением игроков, подключение к уже идущему матчу, итоги матча.

## Запуск локально

Нужен любой статический сервер (модули ES не работают через `file://`):

```sh
python3 -m http.server 8080
```

Затем открыть `http://localhost:8080`.

## Как устроен мультиплеер

Соединение P2P через WebRTC ([PeerJS](https://peerjs.com/)). Браузер создателя комнаты работает хостом: считает урон, счёт, возрождения, управляет ботами и рассылает состояние остальным. Для первичного знакомства браузеров используется бесплатный публичный сервер PeerJS (`0.peerjs.com`). Если хост выходит, комната закрывается.

Для проверки можно поднять свой сервер соединений и указать его в адресе:

```sh
npx peer --port 9000 --path /
# http://localhost:8080/?peerHost=localhost&peerPort=9000
```

## Структура

```

css/style.css     стили
src/main.js       меню, лобби, роли хоста и клиента
src/game.js       сцена, игрок, стрельба, сетевые события
src/match.js      логика матча на хосте и боты
src/net.js        обёртка над PeerJS
src/map.js        карты и коллизии
src/physics.js    движение, лучи, хитбоксы
src/weapons.js    характеристики и модели оружия
src/viewmodel.js  оружие и руки от первого лица
src/avatar.js     модели других игроков
src/textures.js   процедурные текстуры
src/effects.js    трассеры, частицы, следы, гильзы
src/audio.js      синтезированные звуки
src/hud.js        интерфейс в бою
vendor/           three.js r186 и PeerJS 1.5.5 (MIT)
```
